# Logical Components: frontend-core

## コンポーネント構成

frontend-coreは以下3つの論理コンポーネントで構成する。

| コンポーネント | 責務 | 依存 |
|---|---|---|
| 画面コンポーネント | ログイン、トップ(テーブル・メニューのカード一覧)、一覧、詳細、編集(新規/更新)、アカウント自己サービス系(パスワード忘れ・登録完了・氏名/パスワード変更・メールアドレス変更)、ロール切替、ログアウトの各画面 | 共通UIコンポーネント、APIクライアント |
| 共通UIコンポーネント | FkReferencePicker(FK参照ポップアップ検索)、LoginLockoutNotice(ログインロック通知)等のmake-you-chic-uiベース部品 | APIクライアント |
| APIクライアント | バックエンドREST呼び出しの共通化、アクセストークン・リフレッシュトークンの保持、401検知時の自動リフレッシュと元リクエストの再試行、X-Active-Roleヘッダーの付与 | (バックエンドREST API) |

## 障害ドメインとブラストラディウス

frontend-core自身の障害はUI表示のみに影響し、バックエンドの状態には影響しない。APIクライアントのトークン管理不具合(既知のNFR-AUTHN.1ギャップ含む)は、認証セッションの継続性に影響するが、バックエンド側のセキュリティ制御(署名検証・失効判定)自体は健全に保たれる(誤ってセッションが早期終了する方向の不具合であり、認可バイパスにはならない)。

## 共有リソース

frontend-core自身は永続化状態を持たない。アクセストークン・リフレッシュトークンはAPIクライアントコンポーネントがクライアント側(ブラウザ)で保持し、frontend-adminを含む他の画面群からも同一のAPIクライアントを共有して参照する。
