# Observability Design: audit-log

## 構造化ログ

記録受付処理の失敗時(BR1.2)、JSON形式の構造化ログをERRORレベルで出力する。含めるフィールドはactionType・occurredAt・例外メッセージ(スタックトレースを含む)の3種とし、イベントpayload全体・機微情報は含めない。

## メトリクス

Spring Boot Actuator + Micrometerの標準メトリクス(HTTPリクエストのレイテンシ・ステータスコード分布等)をそのまま利用する。本Unit固有のカスタムメトリクス(記録失敗件数等)は追加実装しない(構造化ログでの追跡に委ねる、軽量版方針)。

## 分散トレーシング

Spring Boot標準のOpenTelemetry自動計装(NFR3)に委ね、本Unit固有の追加のトレーシング実装(カスタムSpan生成等)は行わない。

## アラート・ダッシュボード

自宅サーバ1台での個人利用のため、専用のアラートルール・ダッシュボードは設計しない。構造化ログの確認は運用者の手動対応とする。
