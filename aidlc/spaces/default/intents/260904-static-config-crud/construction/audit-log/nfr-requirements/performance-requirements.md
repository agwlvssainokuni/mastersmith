# Performance Requirements: audit-log

## NFR1.1: 応答速度の一般方針

requirements.md NFR1を踏襲する。自宅サーバ1台・個人利用中心の運用のため、厳密な数値目標(p95/p99レイテンシ等)は設けない。実用上問題のない応答速度であればよい。監査ログ画面(参照・エクスポート)の初期表示に数秒以上かかるなど著しい遅延の兆候が確認された場合は、その時点で別途性能検証を行う。

## NFR1.2: 大量データ対策

監査ログの参照は、ページネーション(page/size、functional-design契約#18)を前提とした設計であり、一括全件取得は行わない(BR2.1・BR2.2)。エクスポート(BR3.1)は現在の絞り込み条件に一致する範囲のみを対象とし、無条件の全件エクスポートを既定動作としない設計とすることで、データ量増加時の性能劣化を構造的に抑制する。追加のキャッシュ・インデックス設計は、実装段階(Code Generation)でのDB選定・実測に委ねる。
