# Reliability Design: schema-ingestion

自宅サーバ1台構成のため、SLA/SLO形式の数値目標は設けない。

## ステートレス設計による復旧の単純さ

本Unitはステートレスであり、走査結果を永続化しない(NFR-RESILIENCE.1)。業務DBへの接続失敗・走査失敗は例外として呼び出し元(config-management)へ伝播し、REST境界では500として応答する(BR6.1)。本Unit自体の障害からの復旧はアプリケーションの再起動のみで完結し、専用のリカバリ手順(データ復元等)は不要である。

## リトライ・サーキットブレーカー

リトライは行わない。接続失敗はそのまま呼び出し元へ伝播させ、再試行の要否は管理者の判断(接続テスト画面での再実行)に委ねる。本Unit自体はサーキットブレーカーを実装しない(業務DBへの単発的な接続試行であり、連続呼び出しによる障害波及を防ぐ必要性が低いため)。

## ヘルスチェック

Spring Boot Actuatorの標準`/actuator/health`エンドポイントに委ねる。
