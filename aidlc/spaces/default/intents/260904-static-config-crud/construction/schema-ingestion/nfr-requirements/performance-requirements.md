# Performance Requirements: schema-ingestion

## NFR1.1: 応答速度の一般方針

requirements.md NFR1を踏襲する。厳密な数値目標(p95/p99レイテンシ等)は設けない。実用上問題のない応答速度であればよいが、著しい遅延の兆候(例: プレビュー画面の初期表示に数秒以上かかる)が確認された場合は、その時点で別途性能検証を行う。

## NFR1.2: スキーマ走査の性能特性

スキーマ走査(JDBC DatabaseMetaData呼び出し)はテーブル数に比例して時間がかかりうるが、個人利用中心の想定業務規模(数十〜数百テーブル程度)では実用上問題ない範囲とする。著しい遅延が確認された場合は、取り込み対象テーブルの絞り込み(プレビュー画面での選択)で対応し、走査ロジック自体の最適化(並列化等)は本ステージでは規定しない。
