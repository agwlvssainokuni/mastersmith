# Performance Requirements: auth

## NFR1.1: 応答速度の一般方針

requirements.md NFR1を踏襲する。厳密な数値目標は設けない。著しい遅延の兆候(例: ログイン処理に数秒以上かかる)が確認された場合は、別途性能検証を行う。

## NFR1.2: Argon2ハッシュ照合とのトレードオフ

ログイン処理(BR1.1)はArgon2によるパスワードハッシュ照合(NFR7、BR5.1)を含む。Argon2は意図的に計算コストが高いアルゴリズムであり、他の操作より応答が遅くなること自体は、ブルートフォース耐性というセキュリティ目的とのトレードオフとして許容する。具体的なArgon2パラメータ(メモリ・反復回数)のチューニングはコード生成段階で行う。
