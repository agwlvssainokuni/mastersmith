# Observability Requirements: permission

## NFR3.1: Twelve-Factor App準拠・構造化ログ

requirements.md NFR3を踏襲する。プロジェクト全体の横断要件であり、本Unit固有の追加要件はない。

## 権限判定の可観測性

拒否(403)判定が発生した場合、実装段階で判定理由(テーブル単位デフォルト拒否か、明示的な権限不足か)を区別できるログを残すことが望ましいが、レスポンス自体には理由の詳細を含めない(セキュリティ上、拒否理由の詳細を攻撃者に開示しないため)。専用のダッシュボード・アラート設計は、本プロジェクトの運用規模に照らして本ステージでは規定しない。
