## Q3. 一覧・詳細画面で外部キー(FK)の値を表示する際、参照先テーブルの代表的な列の値(例: 商品IDではなく商品名)で表示したい場合、その名称解決はどうしますか?

X. Other (please specify)

[Answer]: A. 静的設定駆動の原則の例外として、画面表示のたびに参照先テーブルへ実行時に問い合わせて名称を取得する。加えて、登録・編集画面のFK入力項目では、参照先レコードをポップアップの検索画面で検索・選択できる補助機能を提供する(主キーの直接入力も引き続き可能)。
