# Refined Mockups: MasterSmith MVP

rough-mockups(`wireframes.md`)の8画面群を土台に、requirements-analysisで追加された機能(設定管理CRUD、FK参照ポップアップ検索、監査ログ、管理者アカウント管理、ログイン試行回数制限)を精細化する。デザインシステムは自作の `make-you-chic-ui`(AppShell・Table・フォーム部品・4軸テーマ機構)を用いる。方針確認(refined-mockups-questions.md Q1〜Q7)に基づき、既存パターン(一覧画面・ロール管理画面群)の再利用を基本とする。

配色・テーマの作り分け(4軸テーマ)は業務インスタンスごとに設定可能とし、具体的なテーマトークン一覧は本ドキュメントでは扱わず、design-system-mapping.mdで扱う。
