# User Flow — MasterSmith(マスタ管理アプリ)

## Flow: ロールの切り替え(複数ロールを持つユーザ)

```
Flow: ロールの切り替え
Persona: 複数ロールを持つ社内の業務担当者
Trigger: 現在のロールとは別の権限で操作したい
Steps:
  1. [任意の画面] -> ヘッダーのロール選択(トップ画面, wireframes.md参照)を開く -> ロール一覧が表示される
  2. ロール選択 -> 別のロールを選ぶ -> 選択中ロールが切り替わり、サイドバー・一覧・詳細編集の表示可否がロールの権限に応じて更新される
Success outcome: ヘッダーに選択中のロールが表示され、以降の操作は選択したロールの権限に従う
Error paths:
  - 単一ロールしか持たないユーザ -> ロール選択自体が表示されない
```

## Flow: マスタデータの参照・編集(ハッピーパス)

```
Flow: マスタデータの参照・編集
Persona: 社内の業務担当者
Trigger: ログイン後、対象テーブルのデータを確認・修正したい
Steps:
  1. [トップ画面] -> サイドバーで対象テーブルを選択 -> [一覧画面]へ遷移
  2. [一覧画面] -> 検索条件を入力し「検索」を押す -> 絞り込まれた一覧が表示される
  3. [一覧画面] -> 対象行の「詳細」を押す -> [詳細・編集画面]へ遷移
  4. [詳細・編集画面] -> 項目を編集し「保存」を押す -> 保存確認メッセージ表示 -> [一覧画面]に戻る
Success outcome: 一覧画面に戻り、更新された内容が反映されていることを確認できる
Error paths:
  - バリデーションエラー(必須未入力・形式不正) -> 詳細・編集画面にインラインでエラー表示 -> 該当項目を修正して再保存
  - 保存時の競合・DBエラー -> 画面上部にエラーメッセージ -> 一覧画面には遷移せず、詳細・編集画面に留まる
  - 権限不足でアクセス不可のテーブル -> サイドバーに当該メニュー項目自体が表示されない(Q5)
```

## Flow: 新規データの作成

```
Flow: 新規データの作成
Persona: 社内の業務担当者
Trigger: マスタデータを新規に追加したい
Steps:
  1. [一覧画面] -> 「+ 新規作成」を押す -> [詳細・編集画面(新規)]へ遷移
  2. [詳細・編集画面] -> 各項目を入力し「保存」を押す -> 保存確認メッセージ表示 -> [一覧画面]に戻る
Success outcome: 一覧画面に新規データが追加されて表示される
Error paths:
  - バリデーションエラー -> インライン表示、修正して再保存
  - CREATE権限がない -> 「+ 新規作成」ボタン自体が非表示(Q5)
```

## Information Architecture(情報構造)

```
トップ画面(Card形式メニュー)
├── 業務メニュー(N階層、Q9)
│   ├── グループA
│   │   ├── テーブル1 一覧 → 詳細・編集
│   │   └── テーブル2 一覧 → 詳細・編集
│   └── グループB
│       └── テーブル3 一覧 → 詳細・編集
└── 管理メニュー(権限がある場合のみ)
    ├── 業務メニュー設定(DB接続先/スキーマ読込/表示項目/権限/メニュー構成)
    ├── ユーザ管理(登録/更新/無効化)
    └── 監査ログ管理(記録の閲覧)
```

- ナビゲーション階層は最大N階層(業務メニュー配下)。すべての画面はサイドバーから直接到達可能(パンくずなし、Q9)
- 表示・遷移可能なメニュー項目は権限制御(RBAC)に従って動的に変わる([scope-document] Q5)
