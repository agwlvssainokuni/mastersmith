# Wireframes — MasterSmith(マスタ管理アプリ)

対応デバイス: デスクトップ + タブレット(Q3)。アクセシビリティは一般的な配慮(キーボード操作可能・ラベル付与)で十分とする(Q4)。

## 1. トップ画面(ログイン後の初期表示)

Q1で確定した通り、メニューをCard形式で並べる専用のトップ画面。

```
+--------------------------------------------------------------+
| [Logo] MasterSmith        [ロール: 一般ユーザ ▼] [User] [Logout]|
+--------------------------------------------------------------+
|                                                                |
|  業務メニュー                                                  |
|  +------------+  +------------+  +------------+               |
|  | [Icon]     |  | [Icon]     |  | [Icon]     |               |
|  | グループA   |  | グループB   |  | グループC   |               |
|  | テーブル1,2 |  | テーブル3   |  | テーブル4,5 |               |
|  +------------+  +------------+  +------------+               |
|                                                                |
|  管理メニュー(権限がある場合のみ表示)                           |
|  +------------+  +------------+  +------------+               |
|  | 業務メニュー |  | ユーザ管理  |  | 監査ログ    |               |
|  | 設定       |  |            |  | 管理       |               |
|  +------------+  +------------+  +------------+               |
+--------------------------------------------------------------+
```

- アクセシビリティ: h1「MasterSmith」、ランドマークは header/main、キーボードエントリーポイントはヘッダーのロール選択(Tab移動でカードへ)
- 権限により表示されないカード(グループ・管理メニュー項目)は非表示(Q5)
- **ロール選択(R-01対応)**: 複数ロールを持つユーザは、ヘッダー右側の「ロール: [選択中のロール] ▼」で操作するロールを切り替える。選択したロールは以降の全画面(サイドバー・一覧・詳細編集)に適用され、ヘッダーに常時表示される。単一ロールのユーザにはロール選択自体を表示しない
- **表示設定(ユーザーメニュー内)**: ヘッダーの[User]アイコンをクリックすると開くメニューに、テーマ選択(ライト/ダーク)とフォントサイズ選択(大/中/小)を追加する。選択内容はユーザー単位で保持し、全画面に適用する
  ```
  [User] クリックで展開:
  +----------------------+
  | テーマ: ○ライト ●ダーク |
  | 文字サイズ: 小 中(●) 大 |
  |----------------------|
  | ログアウト             |
  +----------------------+
  ```
- Empty状態: 権限のあるメニューが1件もない場合は「利用可能なメニューがありません。管理者にお問い合わせください」を表示
- Loading状態: カード部分をスケルトン表示
- Error状態: メニュー取得に失敗した場合、画面上部にインラインでエラーメッセージと再読み込みボタンを表示

## 2. サイドバー(共通ナビゲーション、一覧・詳細画面で表示)

業務メニュー配下にマスタメンテのメニューをN階層、管理メニュー配下に管理者機能(scope-document.md参照)。パンくずリストはなし。ヘッダーのロール選択(1参照)に従い、表示項目は選択中のロールの権限に基づいて変わる。

```
+----------+---------------------------------------------------+
| [ロール: 一般ユーザ ▼]                     [User] [Logout]     |
+----------+---------------------------------------------------+
| Sidebar  |  Main Content                                     |
|----------|                                                    |
| 業務メニュー|                                                    |
| ▸グループA|                                                    |
|  ▸サブグループA-1                                               |
|   ・テーブル1(選択中)                                           |
|   ・テーブル2|                                                   |
|  ・テーブル3(サブグループなし直下)                               |
| ▸グループB|                                                    |
| 管理メニュー|                                                    |
| ▸業務メニュー設定                                                |
| ▸ユーザ管理|                                                    |
| ▸監査ログ管理                                                    |
+----------+---------------------------------------------------+
```

- アクセシビリティ: h1(サイドバー見出しは視覚非表示のh1「ナビゲーション」)、nav/main landmark、選択中の項目はaria-current="page"相当で示す、キーボードでの上下移動対応、キーボードエントリーポイントはサイドバー先頭のメニュー項目

## 3. 一覧画面

```
+----------+---------------------------------------------------+
| Sidebar  |  [テーブル1] 一覧                                    |
|          |  +------------------------------------------+      |
|          |  | 検索条件(主要のみ) [詳細検索 ▼]  [検索][クリア]|      |
|          |  +------------------------------------------+      |
|          |  [+ 新規作成]                                       |
|          |  +------------------------------------------+      |
|          |  | □ | 列1▲| 列2 | 列3 |         | 操作      |      |
|          |  |---|-----|-----|-----|---------|----------|      |
|          |  | □ | ... | ... | ... |         | [詳細]    |      |
|          |  +------------------------------------------+      |
|          |  < 1 2 3 ... 10 >   全123件                        |
+----------+---------------------------------------------------+
```

- 検索条件は折りたたみ可能。デフォルトは主要条件のみ表示、「詳細検索」で展開(Q6)
- 一覧に表示する項目は権限制御とは独立した表示可否設定に従う([scope-document] Q6)。READ権限のないカラムは列自体を非表示(Q5)
- アクセシビリティ: h2「[テーブル名] 一覧」、main landmark、テーブルはtheadでソート可能列を示す、キーボードエントリーポイントは検索条件の最初の入力欄
- Empty状態: 「該当するデータがありません。検索条件を変更してください」
- Loading状態: テーブル部分をスケルトン表示
- Error状態: 検索条件の上部にインラインでエラーメッセージ

## 4. 詳細・編集画面

```
+----------+---------------------------------------------------+
| Sidebar  |  [テーブル1] 詳細・編集            [一覧に戻る]       |
|          |  +------------------------------------------+      |
|          |  | 項目1(必須)   [________________]          |      |
|          |  | 項目2         [________________]          |      |
|          |  | 項目3(select) [▼ 選択してください  ]        |      |
|          |  | 項目4(読取専用) 値のみ表示                   |      |
|          |  +------------------------------------------+      |
|          |  [保存]  [キャンセル]                              |
+----------+---------------------------------------------------+
```

- フォーム部品は設定駆動(1行テキスト/複数行テキスト/整数値/小数値/日付/日時/select/radio/switch/checkbox)([scope-definition]参考ドラフト)
- 編集不可の項目は読取専用表示。権限がREAD未満の項目は非表示(Q5)
- バリデーションはフィールドのフォーカスアウト時にインライン表示
- アクセシビリティ: h2「[テーブル名] 詳細・編集」、main landmark、必須項目にはaria-required、エラーメッセージはフィールド直下に表示しaria-describedbyで関連付け、キーボードエントリーポイントは最初の入力欄
- 保存成功時: 画面上部にインライン確認メッセージを表示し一覧へ戻る
- Loading状態: 既存データ取得中はフォーム部分をスケルトン表示、保存処理中は「保存」ボタンを非活性化しスピナーを表示
- Error状態: 保存失敗時はエラー内容をフィールドごとに表示
