# Accessibility Checklist — MasterSmith(マスタ管理アプリ)

要件定義書 NFR6「キーボード操作可能・ラベル付与等、一般的な配慮」および `refined-mockups-questions.md` Q10の回答(B)に基づき、本チェックリストはWCAG準拠レベルを明示的な達成目標とはせず、個別項目単位でのチェックリストとして定義する。

## キーボード操作

- [ ] すべてのインタラクティブ要素(ボタン、リンク、フォーム部品、メニュー、モーダル)がキーボードのみで操作できる
- [ ] Tabキーでのフォーカス移動順が視覚的なレイアウト順(左から右、上から下)と一致している
- [ ] すべてのフォーカス可能要素に、視認できるフォーカスインジケーター(アウトライン等)が表示される。`outline: none` を代替なしで使用しない
- [ ] モーダルダイアログ(一括削除確認、CSVインポートエラー一覧、JSON設定インポート確認等)は、開いている間キーボードフォーカスをモーダル内にトラップし、Escapeキーで閉じられる
- [ ] モーダルを閉じた後、フォーカスはモーダルを開いた操作要素へ戻る
- [ ] サイドバーのツリーナビゲーションは矢印キーでの上下移動に対応する
- [ ] ロール選択セレクタ・テーマ/フォントサイズメニューは矢印キーでの選択肢間移動、Enter/Spaceでの確定に対応する
- [ ] 一覧画面の各画面(ログイン、トップ、一覧、詳細・編集、ユーザ管理、監査ログ、業務メニュー設定、設定管理)に、最初のキーボードエントリーポイントが明確に定義されている(`mockups.md` 各画面の記載を参照)

## ラベル付与

- [ ] すべてのフォーム入力欄に、視覚的な`<label>`が関連付けられている(placeholderのみに依存しない)
- [ ] 必須項目には視覚的な「(必須)」表示に加え、`aria-required="true"` を付与する
- [ ] アイコンのみのボタン(検索アイコン、削除アイコン等)には `aria-label` を付与する
- [ ] ロール選択セレクタ、テーマ/フォントサイズメニューなど本アプリ固有のコンポーネントには、視覚ラベルまたは `aria-label` のいずれかを必ず付与する(`interaction-spec.md` 各コンポーネント仕様を参照)

## エラー・フィードバック表示

- [ ] バリデーションエラーは、赤色などの色のみに依存せず、アイコンまたはテキストでも識別できる
- [ ] エラーメッセージはフィールドの直下に表示し、`aria-describedby` でフィールドと関連付ける
- [ ] 楽観ロック競合エラー・保存失敗・CSVインポートエラー等のインラインバナーは `role="alert"` を用い、表示と同時にスクリーンリーダーへ通知される
- [ ] エラーメッセージは開発者向けのスタックトレースやエラーコードではなく、利用者が理解できる自然文で表示する(FR6.2, `interaction-spec.md` fail fastの扱いを参照)
- [ ] テーマ・フォントサイズの変更完了、一括削除の完了など、状態変化を伴う操作の結果は `aria-live="polite"` 等で通知する

## コントラスト・視覚表現

- [ ] 通常テキストは背景色に対して4.5:1以上のコントラスト比を確保する
- [ ] UIコンポーネント(ボタン境界、フォーカスインジケーター等)は3:1以上のコントラスト比を確保する
- [ ] ライトテーマ・ダークテーマの両方で上記コントラスト基準を満たす
- [ ] 権限により項目やメニューが非表示になる場合、色や濃淡のみで「無効」を表現せず、要素自体を非表示にする(`mockups.md` の権限制御方針と整合)

## 見出し構造・ランドマーク

- [ ] 各画面に適切なランドマーク(`header`, `nav`, `main`)を設定する(ラフモックアップ4画面は`wireframes.md`の記載を踏襲、本ステージで新規追加した6画面(ログイン、初期パスワード設定、ユーザ管理、監査ログ閲覧、業務メニュー設定、設定管理)は`mockups.md`の各画面記述に従う。レビュー指摘R-03への対応)
- [ ] 各画面に一意のh1(またはページタイトルとして機能する見出し)を設定する(サイドバー等、視覚的に非表示とする見出しも含む)
- [ ] 見出しレベル(h1〜h6)を飛ばさず、論理的な階層で使用する
- [ ] 言語切替(日本語/English)を行った際は、表示文言の切替と同時に文書のルート要素の言語指定を選択言語に更新する(レビュー指摘R-11への対応、`interaction-spec.md`のDisplaySettingsMenu参照)

## フォーム・入力支援

- [ ] バリデーションはフィールドのフォーカスアウト時に行い、入力中の過度な割り込みを避ける(`wireframes.md` の記載を踏襲)
- [ ] 日付・数値等、書式が定まっている入力欄には期待する書式のヒントを表示する
- [ ] 読取専用項目・非表示項目は権限に応じて一貫した表現方法(読取専用表示 or 非表示)を用いる(FR6.4)

## その他

- [ ] コンテンツが1秒間に3回を超えて点滅する演出を使用しない
- [ ] アニメーション(トースト表示、モーダルの開閉等)は `prefers-reduced-motion` を尊重し、無効化できるようにする

## Assumptions & Open Questions

None。
